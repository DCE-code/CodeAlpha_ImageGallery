# Frame — Responsive Image Gallery

A responsive image gallery built for the CodeAlpha Frontend Development internship using semantic HTML5, modern CSS and vanilla JavaScript.

## Features

- Responsive CSS Grid layout for mobile, tablet and desktop.
- Category filters: Nature, Architecture, Travel and Lifestyle.
- Live search by title, location or category.
- Accessible lightbox with previous/next navigation.
- Keyboard navigation: Escape to close, arrow keys to move.
- `/` keyboard shortcut to focus search.
- Dark/light theme toggle with localStorage persistence.
- Reduced-motion preference support.
- Semantic landmarks, accessible labels and descriptive image alt text.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. For a local development server, use the VS Code Live Server extension.

## Images

Demo images are loaded from Unsplash via remote image URLs. An internet connection is required to display them. Replace the image URLs in `index.html` with your own licensed images before publishing if preferred.
